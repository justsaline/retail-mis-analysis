# Retail MIS Analysis

This project demonstrates a formula-driven Excel MIS built to simulate
daily sales reconciliation using electronic journal (EJ) style retail data.

## Project Overview
- Reconciles daily store sales and returns
- Separates online and offline transactions
- Calculates net sales and transaction volume
- Flags high return activity for operational review

## Tools Used
- Microsoft Excel

## Files
- `Daily_Sales_Reconciliation_MIS.xlsx` – Daily store performance summary MIS

## Notes
Data used in this project is simulated for learning and demonstration purposes.
